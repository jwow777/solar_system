# Атлас Солнечной системы

Интерактивная 3D-модель на Three.js и TypeScript: Солнце, 8 планет, 5 карликовых планет и 18 спутников.

Папка проекта, npm-пакет и [репозиторий GitHub](https://github.com/jwow777/solar_system) называются `solar_system`, краткое название в интерфейсе — «Солнечный атлас».

[Открыть приложение](https://jwow777.github.io/solar_system/)

## Запуск

Требуется Node.js 22.20+ и браузер с WebGL2.

```sh
cd solar_system
npm ci
npm start
```

Команды выполняются из папки `solar_system`. Скрипты определяют расположение файлов относительно самих скриптов, поэтому переименование локальной папки не требует изменения путей к текстурам и данным.

Приложение доступно по адресу http://localhost:8080/. Перед запуском автоматически готовятся текстуры. Первый запуск занимает больше времени; неизменившиеся карты затем используются повторно.

## Управление

- Перетаскивание сцены вращает камеру, колесо мыши или жест двумя пальцами меняют расстояние.
- Каталог с миниатюрами разделён на планеты, карликовые планеты и спутники. Поиск работает сразу по всем 32 объектам. Выбор открывает карточку и включает слежение камеры; на телефоне каталог открывается кнопкой в верхней панели.
- В карточках планет и спутников вкладка «Характеристики» показывает основные сведения, «Орбита» — текущие расстояние и скорость, а также параметры орбиты. Для спутников расстояние считается от центра планеты в километрах.
- Клик по телу в сцене открывает его карточку. Перетаскивание камеры не считается кликом.
- Нижняя панель времени включает паузу и перемещает симуляцию на ±10 дней. Шаги работают и на паузе. На широком экране доступны быстрые скорости 0,1 / 1 / 10 дней в секунду; на любом экране скорость можно задать в настройках.
- При каждом запуске симуляция начинается с текущих даты и времени устройства. Поле даты показывает UTC и позволяет выбрать другую дату; математическая опорная эпоха остаётся J2000.
- Орбиты полупрозрачны: 12% непрозрачности у планет и 9% у спутников. Наведение на линию или само тело выделяет соответствующую орбиту с полной непрозрачностью; при уходе указателя восстанавливается обычный вид.
- «Общий обзор» показывает всю систему и отключает слежение.
- Настройки сцены открываются в верхней панели и сохраняются в браузере: освещение, эффекты, масштаб, орбиты и скорость времени. Кнопка сброса возвращает исходные значения.
- В начале настроек есть раздел «Масштаб и время» с двумя независимыми переключателями. «Реальные размеры и расстояния» приводит Солнце, планеты, спутники и основные кольца Сатурна к общим единицам планетных орбит. Маленькие тела удобно выбирать через каталог — камера приближает их автоматически.
- «Реальные скорости — время 1:1» задаёт одну секунду симуляции на одну секунду активной работы и убирает замедление суточного вращения. В нижней панели появляются часы UTC. Пауза, дата и шаги ±10 дней остаются доступны; при выключении возвращается прежнее ускорение времени. Размеры и скорость можно переключать отдельно, оба выбора сохраняются в браузере.
- Навигация работает с клавиатуры (Tab, Enter); стрелки переключают вкладки, Ctrl/Cmd+K или `/` открывают поиск. Escape закрывает настройки или карточку и возвращает фокус.

## Сборка и проверки

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

Сборка автоматически готовит текстуры, проверяет TypeScript и запускает модульные тесты. Production-preview: http://localhost:4173/solar_system/.

Проверка в браузере:

```sh
npx playwright install chromium
npm run test:e2e
```

Предварительно выполните `npm run build`. Playwright самостоятельно запускает сервер preview. При необходимости путь к установленному Chromium можно задать переменной `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

GitHub Actions проверяет сборку, математику, время, камеру, текстуры, навигацию и основные сценарии интерфейса.

## Публикация

Сайт публикуется автоматически: workflow `.github/workflows/deploy-pages.yml` собирает проект при каждом пуше в `master` и выкладывает содержимое `dist` на GitHub Pages. В настройках репозитория достаточно один раз выбрать источник публикации **Settings → Pages → Source → GitHub Actions**.

Адрес приложения: https://jwow777.github.io/solar_system/. Сборка использует базовый путь `/solar_system/`, браузерные проверки запускают preview по тому же пути. Для ручной публикации в ветку `gh-pages` остаётся команда `npm run deploy`, но при включённом источнике GitHub Actions она не используется.

## Текстуры

Исходные карты находятся в `src/assets/maps`. Команда `npm run assets` с помощью Sharp создаёт WebP шириной до 2048 и 4096 пикселей, сохраняя пропорции, прозрачность и исходные файлы.

Готовые файлы расположены в `public/textures`, исключены из Git и генерируются при сборке. Полный набор 2K занимает около 8,39 МиБ, 4K — около 26,44 МиБ. При старте загружаются только 2K. Для выбранного тела подгружаются его карты 4K; при смене объекта предыдущие карты возвращаются к 2K, а лишние GPU-ресурсы освобождаются. Устройства с лимитом текстур меньше 4096 используют 2K. Карты меньшего исходного разрешения не увеличиваются искусственно.

Все 18 спутников имеют локальные текстуры. Для 17 спутников, помимо Луны, загружены карты NASA/JPL/USGS по данным Voyager, Galileo и Cassini. [Источники и обработка](src/assets/maps/moons/README.md) описаны отдельно; сведения также доступны в карточках под пунктом «О текстуре». Титан показан по ИК-карте поверхности, цвета мозаик Cassini усилены, неотснятые области Урана и Тритона заменены ровным серым цветом.

Подготовленные исходники входят в проект: для обычной сборки интернет не нужен. Для повторной загрузки отсутствующих файлов используйте `npm run assets:download-moons`, затем `npm run assets`.

При ошибке загрузки сцена остаётся доступна с имеющимися текстурами; кнопка «Повторить» повторяет неудачные запросы. Цветовые карты имеют sRGB, маски воды/облаков — линейные данные. Tone mapping и преобразование в sRGB выполняются в заключительном OutputPass.

Атмосферы рисуются тонким слоем с приближённым рассеянием света, ослаблением с высотой и тенью планеты. Свечение зависит от Солнца; одинакового яркого ободка вокруг дневной и ночной сторон нет. У Венеры видимый диск образован непрозрачным облачным покровом. У газовых гигантов поверх облачных текстур добавлена только слабая верхняя дымка. Параметры подобраны для визуализации и не являются точными измерениями атмосфер.

Облака Земли находятся в отдельном прозрачном слое и медленно дрейфуют относительно поверхности. Под ними учитывается приближённое ослабление солнечного света; блик на океане зависит от положения камеры. Цвет облачного покрова Венеры приведён к мягкому кремовому оттенку с сохранением рисунка исходной текстуры.

Тень Луны на Земле рассчитывается отдельно в шейдерах поверхности, облаков и атмосферного рассеяния. Перекрытие видимых дисков Луны и Солнца даёт полную тень, полутень и кольцеобразное затмение; затеняется прямой солнечный свет, фоновое освещение сохраняется. Положение и размеры обновляются при рендеринге, в том числе на паузе и после изменения масштаба. Расчёт следует геометрии отображаемой сцены с её условными масштабами и не предназначен для прогнозирования реальных затмений.

## Точность модели

Используются фиксированные эллиптические орбиты с решением уравнения Кеплера. Поле `longitudeOfPerihelion` всегда означает долготу перигелия ϖ; аргумент перигелия вычисляется как ω = ϖ − Ω. Ось Y сцены направлена к северу эклиптики.

[Описание элементов и формул JPL](https://ssd.jpl.nasa.gov/planets/approx_pos.html). Элементы больших планет округлены; элементы и начальные фазы карликовых планет иллюстративные. Возмущения и прецессия не моделируются. Календарь не превращает модель в точную эфемериду.

Все 18 спутников движутся по кеплеровским эллипсам с переменной скоростью. [Снимок JPL Horizons](src/constants/moonOrbitElements.json) содержит оскулирующие элементы и независимые опорные векторы на 29 октября 2026 года, 12:00 UTC: большую полуось, эксцентриситет, наклон к эклиптике J2000, восходящий узел, аргумент перицентра и начальную фазу. Геометрия линии и положение тела используют одну модель. Тритон сохраняет ретроградное движение; дополнительный наклон оси планеты к уже ориентированной орбите не применяется.

Это фиксированные эллипсы на эпоху снимка, а не полный расчёт эфемерид: прецессия, приливная эволюция и взаимные возмущения не учитываются. Вдали от эпохи точность положения уменьшается. Указанный в карточках спутников период — оскулирующий, он может отличаться от среднего периода обращения. Для точных положений на произвольную дату используйте [JPL Horizons](https://ssd.jpl.nasa.gov/horizons/).

По умолчанию размеры тел увеличены, а расстояния спутников сжаты для наглядности. Переключатель реальных размеров использует единый коэффициент `30 / 149597870,7` единиц сцены на километр, сохраняя размерные отношения тел и орбит. Радиусы сфер — средние, эквивалентные по объёму; сплюснутость и трёхосная форма не моделируются. Данные собраны в [physicalData.ts](src/constants/physicalData.ts) по таблицам [планет](https://ssd.jpl.nasa.gov/planets/phys_par.html) и [спутников JPL](https://ssd.jpl.nasa.gov/sats/phys_par/); у Солнца принят номинальный радиус IAU 695 700 км. Размеры основных колец Сатурна задаются радиусами 66 900–136 780 км.

Для Хаумеа взят эквивалентный радиус 797,5 км по [покрытию 2017 года](https://academic.oup.com/mnras/article/478/3/3159/5042072). Период вращения Макемаке — 22,8266 часа по [фотометрии 2019 года](https://doi.org/10.1051/0004-6361/201935274); у Эриды принят синхронный период около 15,79 суток по [исследованию системы Эрида–Дисномия](https://arxiv.org/abs/2303.13445). Неполно известные параметры остаются оценками, а не точными измерениями всех тел.

Масштаб сцены не используется для физических расстояний и скоростей в карточках. Эксцентриситеты не преувеличены: многие орбиты визуально остаются почти круглыми. Спутники Сатурна находятся за внешним краем изображённых колец. Оси планет с моделируемыми спутниками согласованы с [полюсами IAU/NAIF](https://naif.jpl.nasa.gov/pub/naif/generic_kernels/pck/pck00011.tpc). Синхронное вращение спутников вместе с переменной орбитальной скоростью даёт оптическую либрацию. В наглядном режиме вращение планет замедлено до 0,05; в режиме времени 1:1 используются номинальные сидерические периоды без этого множителя. Движение по орбитам остаётся кеплеровским приближением в обоих режимах.

Для обновления снимка выполните `npm run orbits:update-moons -- 2026-10-29T12:00:00.000Z`, указав нужную эпоху, затем пересоберите приложение. Сборка и работа модели используют локальные данные. Скрипт переводит UTC в TDB с приближением TT−UTC=69,184 с (для эпох после 2017 года); периодический член TDB−TT менее 2 мс опускается. При изменении числа високосных секунд конверсию следует обновить.

Часть текстур карликовых планет условная; Плутон использует текстуру Эриды.

Справочные описания и числа известных спутников — статический каталог; при новых открытиях его следует обновлять отдельно.
