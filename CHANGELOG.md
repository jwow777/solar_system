# История изменений

## 1.0.1 — 2026-11-02

### Исправлено

- Каталог на телефоне остаётся над экранной клавиатурой, включая браузеры, которые изменяют только visualViewport. Кнопка каталога больше не вызывает клавиатуру автоматически.
- Устранены наложения вкладок категорий и различия выравнивания названий объектов на узких экранах и в горизонтальной ориентации.
- Повторное нажатие «Обзор» возвращает прежний ракурс, выбранное тело и относительное увеличение. Возврат работает и во время перехода; камера продолжает сопровождение движущегося тела.
- Кнопка закрытия карточки вынесена в отдельную шапку и не перекрывает текст при прокрутке.
- Быстрый выбор скорости доступен на мобильных экранах. Скорость воспроизведения отделена от шага стрелок; её значения подписаны в днях в секунду.
- Подсказка управления показывает жесты для сенсорного экрана и переключается при использовании мыши.
- Приложение использует обновлённый корневой favicon.ico. Удалён старый дубликат из public; в production иконка получает имя с хешем для обновления кеша.
- Визуальные проверки орбиты и освещения Земли ждут замеры до 30 секунд вместо общего лимита 5 секунд, чтобы захват кадра при программном WebGL в CI успевал завершиться. Проверки изменения яркости сохранены.
- Проверка кнопки закрытия карточки ожидает завершения анимации открытия перед сравнением координат.

### Добавлено

- Выбор шага стрелок: 1, 7, 10, 30 или 365 дней. Выбор сохраняется в браузере, работает на паузе и в режиме времени 1:1; по умолчанию остаётся 10 дней.
- Проверки возврата камеры, мобильной клавиатуры, прокрутки карточки, управления временем и подсказок для разных указателей.
- Правило в AGENTS.md: каждое изменение версии сопровождается обновлением CHANGELOG.md, README.md и технической документации в том же коммите.
- Аннотации ошибок Playwright в GitHub и HTML/JSON-отчёты в артефактах CI; JSON с длительностью и результатами визуальных замеров.

### Проверки

- `npm run build`: проверка TypeScript, 145 модульных тестов и production-сборка прошли.
- Локально с `CI=true` проверены 27 сценариев на штатном Chromium Headless Shell для Playwright 1.64.1: 26 прошли в общем прогоне; исправленная проверка крестика прошла в трёх повторных запусках на настольном и мобильном экранах. HTML/JSON-отчёты и вложения с замерами сформированы.
